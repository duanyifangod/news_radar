News Radar is not built because there is not enough news. It is built because there is too much of it.

Every morning, the world has already moved: markets, public affairs, technology, geopolitics, sports, film, music, and culture all keep changing. Your attention, however, does not expand with the news cycle. News Radar gathers the pieces first, then turns them into a briefing you can actually read.

It does not behave like an endless feed. It feels more like a careful morning editor: quiet, organized, and respectful of your time. It puts the stories worth knowing in front of you and keeps the sources nearby. You can read for three minutes or settle in for a deeper pass.

## A Warmer Kind Of News Tool

<p align="center">
  <img src="docs/images/warmnessExperience.png" alt="A warmer reading experience" width="840" />
</p>

News Radar is not trying to make you read more news. It is trying to help you understand the world with less anxiety.

Some stories need immediate attention. Some only need a mental note. Some are worth following slowly over time. A good tool should not manufacture urgency. It should help return attention to you.

If it helps you refresh the screen a few fewer times each morning and leaves a little more room for the work and life that matter, it has done its job.
