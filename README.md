News Radar 想解决的不是“新闻不够多”，而是“新闻太多了”。

每天醒来，世界已经发生了很多事。财经市场、社会事件、科技进展、国际局势、体育赛场、影视娱乐都在更新，但人的注意力并不会因此变多。News Radar 做的事很简单：先替你把信息收拢起来，再整理成一份能读下去的日报。

它不像信息流那样不停推着你往下刷。它更像一位认真但不打扰人的早班编辑，把今天值得知道的事情放到你面前，也把每条新闻的来处留在那里。你可以只看三分钟，也可以慢慢展开读完。

## 一点温度

<p align="center">
  <img src="docs/images/warmnessExperience.png" alt="有温度的阅读体验" width="840" />
</p>

News Radar 不想让你读更多新闻，它希望你用更少的焦虑理解世界。

有些新闻需要立刻知道，有些只需要留个印象，有些值得慢慢追踪。好的工具不应该制造紧迫感，而应该帮你把注意力还给自己。

如果每天早上它能让你少刷几次屏幕，多留一点时间给真正重要的工作和生活，那它就已经完成任务了。
